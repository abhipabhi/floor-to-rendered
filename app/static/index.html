    Take it into a 3D package

      How to open it

      Blender (free) — File ▸ Import ▸ glTF 2.0, pick model.glb. Or run blender --python blender_import.py for a scene with a sun and a camera already set up.

      Twinmotion (free tier) — Import ▸ Geometry ▸ model.glb. Direct Import reads glTF; keep the unit setting at metres.

      Anything else — model.obj with model.mtl beside it.

      Walls, thicknesses, openings, columns and the drawing scale are measured from the PDFs' own vector geometry. Heights are read off the set where a sheet states them and assumed where none does — every one says which, and anything you type stays yours. Nothing here is generated by a model.
